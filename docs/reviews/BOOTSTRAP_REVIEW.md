# Bootstrap Review Notes

## Intentionally Simplified

- One QML module instead of the final multi-module architecture.
- Gradient and opacity materials instead of production shaders.
- Direct mock properties instead of repositories.
- Crossfade navigation instead of the complete identity-preserving transform.
- No real audio.

## Must Be Reviewed on Target Ubuntu

- Font availability and fallback.
- Window sizing under GNOME scaling.
- Qt module packaging.
- Keyboard focus visibility.
- Integrated GPU frame pacing.
- Artwork decoding and caching once real assets are added.
