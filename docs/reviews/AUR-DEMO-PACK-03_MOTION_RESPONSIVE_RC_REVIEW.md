# AUR-DEMO-PACK-03 Review

## Acceptance targets

- F11 enters full-screen presentation mode; Escape returns to a normal window.
- Home, Memory Flow and Music Space remain usable at 920×640 and at 1920×1080.
- The Moment-to-Music transition follows one continuous identity anchor with a subtle arc.
- Reduced Motion avoids continuous drift and uses a short stable transition.
- Eco mode reduces decorative loops without removing music identity.
- Source Studio fits inside the current window and can be closed directly.
- Presence controls still retire automatically; presentation mode retires them faster.
- The preflight script completes dev tests, fixture checks, structure checks, Release build and installation.
- The launch script opens the installed demo and communicates the F11 shortcut.

## Demo RC rule

After this pack, only blocker fixes are allowed before recording: build failure, crash, unreadable layout, broken recall, broken online playback, or truncated user-facing text.
