# AUR-ARTWORK-PARTICLE-FRAGMENT-MOTION-04 Review

This patch does not revert the current direction.

It keeps:
- automatic artwork acquisition,
- 2D illustration generation,
- artwork cache,
- particle extraction,
- asynchronous safety fixes.

It changes only the motion language:
- lower opacity for the intact square image,
- larger outward fragment spread,
- floating suspension motion,
- stronger pitch-driven explosion,
- slower recompose behavior.
