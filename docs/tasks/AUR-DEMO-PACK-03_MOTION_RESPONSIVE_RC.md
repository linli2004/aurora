# AUR-DEMO-PACK-03 — Motion, Responsive and Release Candidate

This three-stage demo pack delivers:

1. AUR-DEMO-09 — Motion and Transition Polish
2. AUR-DEMO-10 — Responsive and Performance Pass
3. AUR-DEMO-11 — Release Candidate

## Scope

- Refine identity travel with a controlled arc and shorter cinematic timing.
- Keep Reduced Motion as a stable cross-fade path.
- Add compact viewport behavior for 920–1080 px windows and shorter displays.
- Reduce continuous work in Eco mode and on constrained viewports.
- Make Source Studio a responsive contextual sheet with an explicit close action.
- Add F11 presentation mode and Escape-to-return behavior.
- Add repeatable preflight and launch scripts for the final demo.
- Freeze the visible Demo RC title and presentation shortcuts.

## Non-goals

- No provider identity migration.
- No new database tables.
- No cloud or synchronization features.
- No new audio analysis algorithms.
