## Frozen Boundaries

This pack does not change:

- SQLite schemas
- online provider resolution
- track/source identity
- Moment persistence
- MPRIS
- local library scanning

## Acceptance

- Music Space no longer uses a centered vertical player composition.
- Crystal acts as an artwork anchor inside a wider identity field.
- The title, artist and Core form one identity group.
- Presence mode keeps only a quiet time trace.
- Control mode returns controls without replacing the central composition.
- Home → Music Space transition preserves the same artwork anchor.
- Reduced Motion remains static and recognition-safe.
