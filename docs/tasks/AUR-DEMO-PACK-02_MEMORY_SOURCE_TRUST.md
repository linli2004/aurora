# AUR-DEMO-PACK-02 — Memory, Source and Trust

This three-stage demo pack delivers:

1. AUR-DEMO-06 — Emotional Memory Timeline
2. AUR-DEMO-07 — Online Music Experience
3. AUR-DEMO-08 — Trust and Failure States

## Scope

- Recompose Memory Flow as a persistent horizontal emotional timeline.
- Keep selection, recall, detached handling and confirmed meaning editing.
- Replace the technical source form with a focused Source Studio.
- Present connected-source and online-track status without exposing raw errors.
- Explain the local-first boundary inside the source experience.
- Preserve Moments when playback or an external source becomes unavailable.
- Remove the redundant current-session period label on Home.

## Non-goals

- No database migration.
- No provider identity redesign.
- No new network permissions.
- No deletion, archive or cloud synchronization.
