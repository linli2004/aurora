# AUR-ILLUSTRATION-PACK-02 — Visual Identity and Dynamic Ink

This pack upgrades the first procedural illustration into a track-stable
music illustration identity.

## Scope

- remove the solid black centre dot;
- introduce a negative-space memory core;
- derive density, openness, asymmetry and tilt from stable track identity;
- strengthen line-weight hierarchy;
- add flowing ribbons, graphite hatching and clustered halftone particles;
- keep the existing public QML API and Music Space integration unchanged;
- preserve Eco, Balanced, Immersive and Reduced Motion behaviour.

## Acceptance

- different tracks produce visibly different compositions;
- the same track keeps the same composition;
- no spectrum bars, HUD or high-saturation effects;
- motion stays inside the illustration;
- pause enters a quieter state instead of freezing abruptly.
