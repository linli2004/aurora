# Aurora Demo RC Runbook

## Preflight

```bash
cd ~/下載/aurora-music-framework
./scripts/demo_preflight.sh
```

## Launch

```bash
./scripts/run_demo.sh
```

Press `F11` for presentation mode. Press `Esc` to return to a normal window.

## 60-second story

1. Open on Home with the latest Moment.
2. Enter the Moment and let the identity transition finish.
3. Wait for Presence Mode; show the music-driven space without controls.
4. Move the pointer to reveal Control Mode.
5. Open Source Studio and play one prepared online track.
6. Leave the controls and let Presence Mode return.
7. Keep the current Moment.
8. Return Home and open Memory Flow to show the new memory.

## Recording freeze

Do not expose Component Gallery, diagnostics, database paths, raw provider errors or terminal output during the recording.
