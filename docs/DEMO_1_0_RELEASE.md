# Aurora Demo 1.0

## Product statement

Aurora Demo 1.0 demonstrates an Ubuntu-native music environment where music identity, atmosphere and personal memory remain continuous.

## Included experience

- Presence-first Music Space
- temporary Control Mode
- artwork-preserving Crystal identity
- local and online playback
- Source Studio with local-first trust language
- persistent Moments and confirmed Meaning
- Memory Flow recall
- presentation-mode launch
- Eco, Balanced and Immersive quality choices
- release preflight, doctor and bundle scripts

## Demo boundary

This release is a qualified product demonstration, not Aurora 1.0 production software. Online provider identity, expired URL re-resolution, memory export and full privacy controls remain post-demo work.
